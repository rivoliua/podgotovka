# Источники для «Анатомии души»

## Автоматически (открытые лицензии)
`python3 scripts/fetch_open_sources.py [папка] [--with-lxx]` — скачивает через git:

| Что | Для чего | Лицензия |
|---|---|---|
| Strong (греч., евр.) | базовые значения, быстрый поиск | общественное достояние |
| BDB + индекс | подробные значения еврейских слов | общественное достояние |
| STEPBible: TBESG, TBESH, TFLSJ (полный LSJ) | современные краткие лексиконы и классический греческий словарь | CC BY 4.0 |
| Abbott-Smith | греческий лексикон Нового Завета | общественное достояние |
| SBLGNT + морфология | греческий текст НЗ | CC BY 4.0 |
| WLC | еврейский текст ВЗ | текст — общественное достояние |
| Септуагинта (Ральфс), по флагу `--with-lxx` | греческий ВЗ | см. лицензию репозитория |
| Синодальный перевод | русский текст | общественное достояние |

Проверка и поиск слова по стихам: сверять значение в TBESG/TFLSJ/BDB, находить употребления в SBLGNT/WLC, русский контекст — в Синодальном переводе.

## Только легально (платные, под авторским правом) — скриптом не скачиваются
BDAG, TDNT (Kittel), Louw–Nida, HALOT. Варианты: купить электронные издания (Logos, Accordance, Olive Tree), взять в университетской/семинарской библиотеке, заказать бумажные издания. Если они уже куплены, их можно открывать в программе-читалке и сверять значения вручную.

## Русские словари
Вейсман (1899, общественное достояние) и Дворецкий — искать в открытых архивах и на Викитеке; в этой среде эти сайты недоступны, поэтому скриптом они не скачиваются.
